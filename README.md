# TraderMade Forex App

This **Forex App** is a Streamlit app designed to keep on top of real-time and historical Currency data from the [TraderMade API](https://tradermade.com/forex). 
The app provides a user-friendly interface to access currency conversion rates, historical exchange rates, volatility, and pivot point analysis.

## Free Signup

To bring this app to life, you'll need a **TraderMade API key**. You can get one by signing up for a free API key:

[**Sign up for a free TraderMade API key here**](https://tradermade.com/signup)

This app supports the following features:

* Real-time currency conversion
* Historical exchange rate data for the last 10 days
* Volatility analysis and pivot point calculation for better forex insights
* Interactive charts and data visualizations using the TraderMade API

![Currency Converter App](https://tradermade.com/static/uploads/streamlit-dashboard.png)

```
git clone https://github.com/Nikhil-Adithyan/TraderMade-Forex-App.git
cd TraderMade-Forex-App

pip install -r requirements.txt

streamlit run app.py
```
